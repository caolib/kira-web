# Kira Web

Kira 漫画阅读器产品展示站（单页）：Vue 3 + Vite + Three.js + Tailwind CSS。

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm preview
```

## 内容

- 文案与链接：`src/content/site.js`
- 截图：`public/screenshots/`（来自产品 README 公开截图）
- Logo：`public/logo.png`
