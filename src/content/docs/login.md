# 令牌登录

## 支持的平台

- 拷贝漫画
- 热辣漫画

## 登录步骤

1.使用电脑，打开拷贝或热辣漫画官网，登录你的账号

2.在浏览器 按F12 或 右键点击检查 打开开发者工具，顶部选择「应用程序」选项，点击侧边栏「Cookie」下的网址，然后在右边找到「token」，将token的值复制

![image-20260811150138435](assets/image-20260811150138435.png)

3.点击登录界面右上角的🔑按钮，然后粘贴刚刚复制的token，完成登录

![image-20260811150341337](assets/image-20260811150341337.png)
