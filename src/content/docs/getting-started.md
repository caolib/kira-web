# 下载与安装

把 Kira 装到设备上，从下一页开始。Kira 是第三方阅读客户端，支持漫画与轻小说阅读。

## 选择安装包

前往 [GitHub Releases](https://github.com/caolib/kira/releases)，展开对应版本的 **Assets**，选择适合设备的安装包。版本信息以发布页为准。

| 设备 | 如何选择 |
| --- | --- |
| Android | 下载 APK。多数较新的手机可选 arm64；其他架构请按设备情况选择。Android 是主要维护平台。 |
| Windows | 选择 Windows 安装包，下载后按提示安装。兼容性及注意事项以对应版本说明为准。 |
| 其他平台 | 可到 [QQ 交流群](https://qm.qq.com/q/rezw7xWuK4) 了解社区构建情况。社区构建不等同于官方维护与发布。 |

## 安装到设备

### Android

1. 将 APK 下载到手机并打开。
2. 如果系统询问安装权限，仅为用于打开此安装包的浏览器或文件管理器开启权限。
3. 按系统提示完成安装。不需要为了安装 Kira 关闭设备安全防护。

请从项目发布页获取安装包，不要安装来源不明的修改版本。

### Windows

打开从发布页下载的安装包，按提示完成安装。如果系统提示不兼容，请先核对发布说明中的架构与系统要求。

## 打开朋友分享的漫画

安装 Kira 后，在系统浏览器中打开朋友分享的链接，点击 **在 Kira 中打开**。

- 聊天应用的内置浏览器可能拦截应用唤起，请尝试用系统浏览器打开。
- 没有安装 Kira 时，可以先从分享页进入下载页面，安装后再回到原链接打开。
- 剪贴板识别默认关闭。如果希望使用此功能，需要先在 App 设置中启用；识别后仍需确认打开。
